# Rate My SBD

An **RShiny application** for evaluating powerlifting performances.  
This app is based on the strength calculator available at [ratemysbd.com](https://ratemysbd.com).  

---

## Features
- Calculate performance metrics across the three powerlifting disciplines: **squat, bench press, and deadlift** (SBD).  
- Compare lifts against strength standards.  
- Interactive and user-friendly interface built with **Shiny**.  

---

## Usage
Launch the app locally in R:  
```r
shiny::runApp("path/to/rate-my-SBD")
